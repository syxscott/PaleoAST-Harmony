# 3D 形态测量数值验证:修 2 处缺陷,并把"未接入"写进文档

## 类型
缺陷修复 / 文档

## 问题

`core/analysis/morpho3d/`(2349 行)是 README 明确宣称的功能(3D 形态测量,5 个分析),
但整包在运行时**不可达**:`morphometrics/index.ts` 不 re-export 它,没有任何文件 import 它,
它导出的 40 个符号在包外被使用次数为 0。

接线之前先做了数值验证(用解析可判定的真值:单位立方体、正四面体、直线 TPS、恒等形变)。
结果发现 2 处真实缺陷,以及若干**经实测确认正确、不应改动**的部分。

## 根因与修复

### 1. `computeNormals` 返回的不是单位向量
`Mesh.ts:148-152` 最后一步把累加好的法向量除以**累加面积权重** `weights[i]`,而不是除以
它自身的模长。面积加权在上面的累加循环里已经做完了,这一步本该只做单位化。

实测:单位立方体的顶点返回 `[-0.2, -0.4, -0.4]`,模长 0.6。任何把返回值当单位法向使用的
地方(着色、曲率、法向的 PCA)都得到系统性错误的结果。

改为按 `sqrt(nx²+ny²+nz²)` 归一。修复后模长精确为 1.0,平面向量恰为 `[0, 0, 1]`。

### 2. `bendingEnergy` 对任何真实形变都是负数
`TPS3D.ts` 报告的弯曲能量实测:5 点锯齿形变给出 **-0.5**,20 组随机三维形变**全部为负**
(最负 -22.75)。弯曲能量按定义非负,而且 `TPSDialog` 的判读提示是 "Energy > 0.1: localized",
负值使这条判读**永远不可能触发**。

根因:原始二次型 wᵀKw 的符号是核归一化的产物,并非单一规则。实测四种核:

| 核 | 原始二次型 | 需要的符号 |
|---|---|---|
| `thin_plate` (U=r,2 阶条件正定) | 负 | 取负 |
| `cubic` (U=r³,严格正定) | 正 | 不取负 |
| `multiquadric` | 负 | 取负 |
| `gaussian` | 负 | 取负 |

先把 `thin_plate` 单独取负后,`cubic` 反而变成负值 —— 证明按核建符号表是脆弱的。
最终报告 `Math.abs(quadratic)`:弯曲能量按定义非负,而绝对标度本就依赖核的归一化,
因此**同一核内的形变之间可比**("这次形变是否局部?"这个问题现在是正确的),跨核不可比。
这一取舍已写进代码注释。

thin_plate 的符号另用独立方法交叉验证:同一拟合下,数值估计的物理量 ∫(y'')²dx = 150,
取负后的二次型与之同号。

## 经实测确认正确、未改动的部分

- **TPS 控制点精确插值**:7 个控制点最大误差 4.4e-16;恒等形变是恒等映射。
- **直线拟合的弯曲权重恰为 0**(直线形变属线性、在 TPS 函数空间内),能量为 0 —— 说明
  线性求解器本身正确,上面的问题只在能量的符号上报。
- **`meshArea` = 6、`computeVolume` = 1**(单位立方体)—— 一直是对的。
- **`computeEdges` 去重正确**:我最初断言立方体应为 12 条边是错的,本项目的三角化每个面
  带一条对角线,18 条(12 棱 + 6 对角)才对。
- **半地标滑动**:固定端点不动、半地标被投影到曲线上,4 项全部通过。
- **`gpa3d` 对正四面体给出距离 0**。

## 决定:暂不接线

修完这 2 处后模块数值上基本可靠,但**本轮仍不接入 UI**。理由:

1. 它没有 UI 入口这件事本身是**文档缺陷**而非代码缺陷,而接线属于加功能,不是修 bug。
2. 弯曲能量的**绝对标度**仍依赖核归一化。把它暴露给用户前,需要先用真实化石数据
   与 R `geomorph::Tps()` 或 Python `scipy.interpolate.RBFInterpolator` 之类参照实现
   对齐标度,否则用户无法判断数值是否合理。
3. 已有 UI 的 `TPSDialog` 走的是 2D `tpsAnalyze`,与 3D 路径不是同一个东西,接线
   需要新增对话框与导航项,应作为独立功能评估。

因此改为在 README 中如实标注,不再宣称未接入的功能。

## 风险

- `Math.abs` 修正的是**符号**,不是标度。跨核比较仍然无意义,注释里已写明。
- 本轮未改动 `Quaternion`——验证时发现它只有 `w/x/y/z` 四个字段、没有暴露矩阵转换方法,
  因此无法对它做旋转性质验证。这是一个独立于本次修复的缺口。
- `gpa3d` 对"旋转+缩放+平移"给出非零 Procrustes 距离(0.813),需确认该实现是否
  按惯例在 GPA 前做尺度归一;本轮未深究。
